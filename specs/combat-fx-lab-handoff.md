# Combat FX Lab 交接與完成紀錄

更新：2026-10-25，Asia/Taipei。

## 任務狀態

先前依使用者指示在額度剩餘 8% 時停止並交接；使用者恢復額度、明確要求繼續後，已完成三個 Phase 的實作、既有正式演出整合及回歸。所有變更留在工作目錄，尚未 commit、push 或建立 PR。

本次完成的是工作台與既有正式結果樣本的整合，不代表每種裝備組合或特殊戰況皆有獨立樣本。無相符樣本時會立即提示並禁止播放。

## 使用方式

1. 開啟 /lab，套用快速情境，或點選左側角色圖像編輯該角色的職業。右側「演出者」指定實際施放者。
2. 配置 1～3 名敵人、調整配置順序。實際站位、Boss 大小仍由正式編隊規則決定。
3. 依序選擇演出者、技能／被動、目標及結果樣本，按播放。裝備與職業條件位於收合設定中。
4. 重播保留情境並重建執行資料；重置演出清除本輪；重置情境回到武士、戰士與單一 Boss。
5. 可切換技能行動、戰鬥開場、回合提示及可獨立預覽的行動步驟。只有正式入口已接通速度參數的演出可調速。

五種快速預設：單一 Boss、三名一般敵人、Boss 搭配隨從、單人技能測試、四人小隊。敵方預設只更換敵方；單人預設保留目前角色一人；四人預設建立武士、智者、卜者、德魯伊。預設不執行另一套戰鬥規則。

## 三個 Phase 的交付

### Phase 1：舞台優先的工作台

- 桌面中央舞台＋兩側收合面板；中等寬度顯示單側設定；手機將設定放在舞台下方。
- 隊伍支援 1～10 人，圖像選角、增減、排序、獨立施放者選擇；敵人支援 1～3 名與主要目標。
- 只展開選中角色的設定，裝備及職業條件預設收合。
- 保留正式頭像、敵人 tier 大小與編隊。多人超出舞台時橫向捲動，指定施放者／受擊者會捲入可見範圍。
- 依隊伍列實際高度保留敵方名稱間距，修正 1024×768 時名稱貼到頭像的問題。
- 播放、重播、兩種重置、步驟進度、全螢幕與退出均接通，沒有假暫停／逐格按鈕。
- 情境資料與執行資料分離；處理 READY、CONFIGURING、PLAYING、FINISHED、RESETTING、ERROR。播放中禁止重複啟動，修改情境會取消舊演出。

### Phase 2：正式演出共用

- iframe 只隔離 DOM／本機顯示狀態，載入正式戰場 DOM、CSS、素材與演出腳本，不載入正式 app.js 或 Socket.IO，不建房、不寫 CMS。
- 從 app.js 原樣抽出敵人／隊友渲染、頭像、tooltip、狀態與 HUD 快照更新到 battle-renderers.js，正式遊戲及 Lab 共用。比對 HEAD，13 個函式內文完全相同，app.js 不保留同名副本。
- 直接呼叫正式 BattleHud、玩家／敵人技能入口、開場與回合提示，沒有另一套 Lab 技能動畫。
- 固定結果轉接器只重映射 ID、目標及顯示快照，不擲骰、不執行傷害或裝備公式。
- 接通連擊、全隊護盾、群體結果、變身／召喚、巢狀觀測、求解相依方程、角鬥場進出等結果契約。
- 修正蝶繭改選盟友時重複修改施放者／覆蓋目標快照，以及非主要敵人施放者的身分。
- 開場沿用正式 presentation-root，敘事時暫隱戰場，由正式入場函式交接，避免提前顯示角色與敵人。
- origin／source 檢查、runId／generation、AbortController 隔離舊請求；取消清理演出節點、動畫、提示框、夥伴視窗及音效。
- 目錄含 15 職業、41 個可配置敵人、539 個樣本選項；樣本選項數不等於不同技能數。

### Phase 3：回歸與清理

- 刪除舊 Lab 控制器、舊 Lab 專屬 CSS 及探索事件樣本，清除其載入／舊路徑引用。
- presentation-lab.js 保留必要契約與驗收資料，移除舊 runtime；沒有為縮小檔案任意拆散資料或移除正式演出。
- 更新 PROJECT_INDEX.md，npm test 納入 Lab 測試。
- 截圖放在儲存庫外，未新增 repo 內 tmp、artifacts、profile、除錯 log。既有使用者 artifacts 未處理。

## 限制與後續

- 不提供暫停、逐格、進度拖曳；未重製動畫計時系統。不支援安全調速者鎖定原速。
- 裝備為單一「裝備演出變體」，不是正式四格配裝／裝備結算器。已接通 12 種裝備的相關樣本：角鬥士三件、殘心羽織、村雨、紫晶球、牌盒、聖契、雙手劍、重弩、妖精木提琴、自然共鳴。
- 有裝備樣本不代表該裝備所有技能／狀態都有樣本；名刀・朧月等裝備、流浪迷宮弩手等無對應樣本的敵人，及其他不相符組合，會直接提示限制並禁止播放。
- 特殊條件依既有樣本提供，不是任意編輯所有內部欄位。Lab 假傷害及觸發結果只用於視覺比較，正式機制仍在 Dev／遊戲驗證。
- 本次是各系統的抽樣視覺回歸，沒有逐一觀看全部 539 個樣本或所有隊伍／裝備組合。
- 後續補覆蓋應新增正式結果樣本或有限的轉接，繼續共用正式演出；無樣本者維持禁止播放。
